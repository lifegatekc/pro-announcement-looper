# Support

Pro Announcement Looper is a free, open-source local-network utility. Source and issue tracker: https://github.com/lcberto/pro-announcement-looper

For setup, see the repository README. Connect Roku and ProPresenter to a network where they can reach one another, enable ProPresenter API access, and use the host and API port shown by ProPresenter. The documented default API port is 50001. No hardcoded church IP addresses are included in the app.

For an offline preview, open Connection & TV settings → Try offline demo. Back or * leaves the demo and restores the original settings. A fresh standalone screensaver with no configured presentations shows bundled samples automatically.

If slides stop updating, check connectivity, use Refresh slides, and keep the previous cache available. Automatic checks retry at the configured interval without stopping the loop. Cache eviction and Roku restarts can require downloading again.

If a screensaver covers the regular player, select the companion screensaver or use Roku Settings → Theme → Screensaver wait/start time to disable the system screensaver yourself. The app does not override Roku's screensaver or simulate activity.

Before opening an issue, note app version, Roku model and OS, which package is installed, and a description of the problem. Redact credentials, IP addresses, private slide images, and other sensitive content from public reports.

Publishers must provide their own support contact information in their Store listing.
